# Circle Website

Projeto Next.js sem Tailwind CSS.

## Começando

Primeiro, instale as dependências:

```bash
npm install
```

Depois, execute o servidor de desenvolvimento:

```bash
npm run dev
```

Abra [http://localhost:2000](http://localhost:2000) no navegador para ver o resultado.

Você pode começar a editar a página modificando `src/app/page.tsx`. A página atualiza automaticamente conforme você edita o arquivo.

## Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento na porta 2000
- `npm run build` - Cria a build de produção
- `npm run start` - Inicia o servidor de produção
- `npm run lint` - Executa o linter
